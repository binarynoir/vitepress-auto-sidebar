# Security Policy

## Supported Versions

Only the latest published version of `@binarynoir/vitepress-auto-sidebar` receives security fixes.

## Reporting a Vulnerability

Please report security vulnerabilities using GitHub's
[private vulnerability reporting](https://github.com/BinaryNoir/vitepress-auto-sidebar/security/advisories/new)
instead of opening a public issue. You should receive a response within a
few days. If the issue is confirmed, a fix will be released and a
[GitHub Security Advisory](https://github.com/BinaryNoir/vitepress-auto-sidebar/security/advisories)
published.
